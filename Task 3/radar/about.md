# Как пользоваться радаром

Радар показывает текущие технологии компании и решения, предлагаемые для целевой архитектуры данных через год.

Кольца означают статус жизненного цикла:

- `Используем` - технология уже применяется и поддерживается.
- `Пробуем` - технология проходит пилот для конкретной бизнес-проблемы.
- `Изучаем` - технология оценивается до начала пилота.
- `Выводим` - технологию не следует использовать в новых решениях; ее заменяют по доменным дорожным картам.

Квадранты группируют языки и фреймворки, методы и паттерны, платформы и эксплуатацию, а также инструменты.

Каждая карточка содержит бизнес-сценарии, которые поддерживает решение, и ограничения, которые нужно учитывать при внедрении.
